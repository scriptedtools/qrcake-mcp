---
description: Point a QR Cake code at a new link
argument-hint: <code name> <new URL>
---

Use the QR Cake qr-codes skill and its "Change a code" section to change the destination of the code named in $ARGUMENTS to the URL given there. If the name or the URL is missing, ask for it. If several codes match the name, ask which one before changing anything. Read the code first, follow the destination rules for its kind, and confirm with the old and the new destination. Say that printed copies now open the new link.
