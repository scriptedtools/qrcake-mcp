---
description: Change how a QR Cake code looks
argument-hint: <code name> [the look you want]
---

Use the QR Cake qr-codes skill and its "Design a code" section for the code named in $ARGUMENTS. If no name was given, or several codes match the name, ask which one. When $ARGUMENTS describes a look (colours, shapes, a logo, a frame), apply it with the design reference and then show the result as that reference describes. When it gives only a name, call design_qr_code once with that code's id so the customer can design it by hand. Do not paste the code's data into the reply, and always add the editor link for a conversation that cannot show the designer.
