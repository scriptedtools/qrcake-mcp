---
description: List all your QR Cake codes
argument-hint: "[optional filter, such as paused or PDF codes]"
---

Use the QR Cake qr-codes skill and its "List every code" section to list the codes the customer owns, read with the list_qr_codes tool. $ARGUMENTS narrows the list if present. Start with the totals, then one table with each code's name, kind, destination, state, scan link and editor link. This command does not modify codes.
