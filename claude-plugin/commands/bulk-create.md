---
description: Create QR Cake codes for a list of links
argument-hint: "[links, or a file of links]"
---

Use the QR Cake qr-codes skill and its bulk create reference to create one code for each link in $ARGUMENTS. If no list was given, ask for one: pasted links, a table, or a spreadsheet. Check the plan limit before creating, confirm the final list when it is long or was changed, and finish with a table of names, destinations, scan links and editor links.
